Ron Tepuy — Sitio Web Oficial
Sitio web institucional y promocional para Ron Tepuy, diseñado para mostrar la esencia, origen e historia de la marca mediante una experiencia visual elegante y un mapa interactivo de Venezuela.

📸 Vista Previa
Sitio web interactivo enfocado en resaltar los puntos clave de origen, destilación y distribución de la marca.

🚀 Características Principal
Mapa Interactivo de Venezuela: Construido con SVG dinámico que permite explorar visualmente regiones clave como Bolívar, Lara (DUSA), Distrito Capital, Miranda y Amazonas con tooltips informativos.

Experiencia Visual Responsiva: Adaptado para una navegación fluida en dispositivos móviles, tablets y pantallas de escritorio.

Diseño Minimalista: Estética oscura enfocada en la sofisticación de la marca, con paleta de colores basada en tonos dorados, piedra y marfil.

Enlace Directo a Compra: Integración con la tienda de distribución oficial para adquisición del producto.

🛠️ Tecnologías Utilizadas
HTML5: Semántico y estructurado.

CSS3: Variables CSS (Custom Properties), Flexbox, Grid y animaciones/transiciones personalizadas.

JavaScript (ES6+): Manipulación del DOM para la interactividad del mapa y cálculo dinámico de posiciones del tooltip.

SVG: Gráficos vectoriales optimizados para la cartografía interactiva.
